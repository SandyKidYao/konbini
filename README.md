# ひかりマート · 桜坂二丁目店

一个放在桌上的 1:150 街角便利店场景模型，用 Three.js + TypeScript 搭建。时间和天气可以分别调整，也可以打开「实况」，跟随你所在地此刻的真实时间和天气。场景还跟着日期走：樱花春开秋红、冬天贩卖机换热饮、过节门口摆上门松或圣诞树、夏日祭的傍晚有人穿浴衣散步。街上有顾客、游客、店员和路人在活动；路上跑着轿车、轻型车、出租车、货车、巡逻警车和社区巴士，车流和车型随时刻、星期和天气变化，有直行也有拐进拐出路口的；也有人开车来店里买东西（从出入口开进门前停车场、车头朝店停好、进店购物、再倒车开走），送货车每天三次来补货。门前人车分流：行人从西侧小广场（贩卖机、自行车停放处、拍照点）或东侧步道走到店门口，车只在停车场里走（车位编号、出入口箭头和「徐行」、出入口的 P 字小牌，天黑后两盏路灯照亮停车场）；人行道上横穿出入口时，人会给开着的车让路。整个场景由一个个「模组」拼成，内容可以按模组扩展。

## 运行

```bash
npm install
npm run dev        # 开发：http://localhost:5173 ，改代码即时刷新
npm run build      # 类型检查 + 打包成单个 dist/index.html（可双击打开）
npm run preview    # 用本地服务器预览打包结果（加载外部模组需要用这种方式）
npm run shots      # 用本机 Chrome 无头截图一组场景到 tmp/shots/，页面报错时失败（先 build）
```

## 桌面版（桌宠，macOS，试验中）

用 Electron 把场景放进一个透明、无边框、浮在最上层的小窗口：桌面上只看到这块底座模型，模型以外的地方点击会穿透到下面的窗口。

```bash
npm run pet        # 打包后打开桌宠
npm run dev        # 另开一个终端：
npm run pet:dev    #   桌宠加载开发服务器，改代码即时刷新
```

- 鼠标移到模型上才接管点击：拖动转一转、滚轮缩放、点小猫和车；底下出现的小把手拖动可以移动窗口（或按住 ⌥ 拖模型）
- 右键模型，或点菜单栏的 🏪：天气、时刻、季节、实况、转台、声音、省电、大小（小 / 中 / 大）、浮在最上层、退出
- 平时 20 帧，指针在模型上时 60 帧；「省电」把平时降到 10 帧。窗口位置、大小、置顶记在用户数据目录的 `pet.json`
- 不显示在 Dock 和 ⌘Tab 里；只能从菜单退出
- 网页版加 `?pet=1` 可以看到同样的透明画面（没有点击穿透和菜单）
- 从 VS Code 扩展里启动的终端可能带着 `ELECTRON_RUN_AS_NODE=1`，Electron 会当成 Node 运行而报错，先 `unset ELECTRON_RUN_AS_NODE`

外壳在 `desktop/`（`main.js` 窗口与菜单，`preload.cjs` 页面与外壳之间的接口），页面这边在 `src/ui/pet.ts`。

## 操作

画面平时只有模型本身。移动鼠标（触屏上轻点一下画面），底部会浮出一条小工具栏，几秒不动又会淡出；拖动模型时立即收起。界面里没有文字说明，全部用图标表示（读屏软件能读到每个按钮的名字）。

- 拖动旋转、滚轮缩放、右键平移。默认静止，不自动转
- 视角：工具栏左边五个图标是预设视角，点一下镜头平滑飞过去（`V` / `Shift+V` 依次切换）。拖动模型后就离开预设
  - 立方体：全景，右前方压低的长焦，整个街角斜着展开，店招看得清楚
  - 店面：正立面，隔着马路正对店门，前景的绿篱虚化
  - 菱形：俯瞰，从西南角斜 45° 往下看，店顶、店面和停车场像一张地图
  - 信号灯：街角，站在路口对面，斑马线、信号灯和来往的车
  - 猫：后院，越过围栏看员工休息角、自动贩卖机和长椅上打盹的猫
- 工具栏右边的滑杆图标打开托盘：
  - 一排天气图标：晴、少云、阴、雾、小雨、雨、雷雨、雪
  - 时间条：拖动太阳改变时刻（指着时显示具体时间）；下面四个小图标（日出、正午、日落、月亮）点一下动画过去
  - 日历图标（下面是日期，橙点表示看的不是今天）：打开日历，第一行四季（樱花、风铃、枫叶、雪人），第二行节日（门松、鬼、星、提灯、南瓜、圣诞树），下面是月历；右下角的回转箭头回到今天
  - 定位图标：实况，跟随你所在地的真实时间、日出日落和天气（每 10 分钟更新），开着时变绿，定位 / 获取中闪烁，出错时带橙点。手动改时间或天气会退出实况
  - 转台、声音、模组列表（失败的模组标红）
- 快捷键：`1`–`8` 天气，`V` 视角，`L` 实况，`R` 转台，`M` 声音，`[` `]` 前后翻一天（加 Shift 一周），`Esc` 关闭面板
- 点击小猫、便利店、后门、自动贩卖机、路上的车和人都会有小反馈（指着可点的东西时光标变成手形）

网址参数：

| 参数 | 例子 | 作用 |
|---|---|---|
| `weather` | `?weather=snow` | 初始天气：`clear` `partly` `cloudy` `fog` `drizzle` `rain` `storm` `snow` |
| `time` | `?time=1750` | 初始时刻（时分） |
| `date` | `?date=2026-07-07`、`?date=12-24` | 指定日期（不写年份就是今年） |
| `season` | `?season=autumn` | 跳到这个季节里的一个典型日子：`spring` `summer` `autumn` `winter` |
| `live` | `?live=1`、`?live=0` | 打开 / 关闭实况（上次打开过会自动恢复） |
| `place` | `?place=35.68,139.69,東京` | 实况用指定地点，而不是定位 |
| `site` | `?site=konbini` | 选择主体 |
| `mods` | `?mods=mods/chochin.js,mods/furin.js` | 加载外部模组（逗号分隔，默认只允许同源相对路径） |
| `disable` | `?disable=konbini.events.traffic` | 关掉某些模组 |
| `view` | `?view=facade` | 初始视角预设：`overview`（默认）`facade` `bird` `corner` `yard` |
| `cam` | `?cam=14,9,16,1.5,0.6,-1` | 任意初始视角 `x,y,z,目标x,目标y,目标z[,视场角]`（优先于 `view`） |
| `warp` | `?warp=60` | 先快进 60 秒的街景再显示 |

## 实况天气

- 位置：先用浏览器定位（会请求权限）；拒绝或失败时用 IP 估计（只有当它的时区和本机一致才采用，避免被代理误导）；再不行就按本机时区选一个城市
- 天气：[Open-Meteo](https://open-meteo.com)（免费、无需密钥），WMO 天气代码决定天气类型，云量、降水、降雪、风速、能见度细化成连续的天气参数
- 地名：BigDataCloud 的反向地理编码
- 上次的结果缓存在浏览器里，下次打开先显示缓存，再后台刷新
- 浏览器定位需要安全上下文（`localhost` 或 https）。直接双击打开打包后的文件时会退回到 IP / 时区估计

## 结构

```
src/
  engine/              与内容无关的运行时
    app.ts             启动、按依赖顺序加载模组、主循环
    mod.ts             模组定义、上下文（ModContext）、依赖排序、外部加载
    atmosphere.ts      时间 × 天气 → 驱动量（日照、云、雨、雪、雾、风、雷、湿度、积雪）与整体观感；今天的日期
    calendar.ts        日期 → 季节、星期、日本节假日、节日、日出日落
    states.ts          随日期、时间、天气切换的离散状态（ctx.states）
    live/              实况：定位、Open-Meteo 天气、定时同步与缓存
    surfaces.ts        地面高度、屋顶、遮雨区域
    nav.ts             步行网络：节点、带宽度/闸门/开门钩子的边、寻路
    agents/            Actor 与脚本步骤、事件调度（Director）；车辆（路径、闸门、跟车与让行，Vehicle / Traffic）
    prefabs.ts         素材库注册表
    services.ts        模组间按名字互相提供服务；消息总线
    glow.ts            自发光材质跟随通道（招牌、店内、窗户、路灯…）
    interact.ts audio.ts stage.ts
    kit/               建模工具、canvas 贴图、随机数
  fx/                  渲染层：全局光、背景、反射、雨、雪与积雪、闪电、湿地面、后期
  content/             所有内容都是模组
    library/           素材库（layer: library）：人偶、柴犬、汽车（轻型车、轿车、出租车、警车…）、货车、巴士、贩卖机、自行车、旗、空调外机、锥桶
    world/             世界环境（layer: world）：底座、道路、街道设施与信号灯、邻里建筑、樱花与云、车道与交通规则
    site/konbini/      主体（layer: site）：店铺、门前场地、员工后院、旗位、节日装饰
    events/            事件（layer: events）：收银员、顾客、店员休息、摆收旗、路人、游客、街上的车、开车来的顾客、送货车
    common/            内置内容共用的色板、贴图、材质
  ui/                  界面（hud.ts：工具栏与托盘；views.ts：视角预设；date-picker.ts：日历；pet.ts：桌宠模式）
desktop/               桌宠外壳（Electron）
public/mods/           外部模组示例（chochin.js：店门口的一串提灯；furin.js：只在夏天挂出来的风铃）
scripts/shots.mjs      无头截图检查（npm run shots）
```

加载顺序：`library → world → site → events → extra`，同层内按 `requires` 排序；缺依赖或出错的模组会被跳过并在托盘的模组列表里标红，不影响其他内容。

扩展方式见 [docs/MODDING.md](docs/MODDING.md)。
